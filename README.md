# Projetos de POO em C#

Exercícios de Programação Orientada a Objetos desenvolvidos em C# (Windows Forms)
durante a disciplina de POO do curso de Ciência da Computação no COTEMIG, em 2022.

## Projetos

| Projeto | Descrição |
|---|---|
| `AppLista03/` | Aplicação Windows Forms com uma série de exercícios de fixação (formulários independentes por exercício) |
| `ProjetoFluxograma/` | Aplicação Windows Forms para representação de um fluxograma |
| `ProjetoMensagem/` | Aplicação Windows Forms para exibição de mensagens |

## Tecnologias

- C#
- Windows Forms (.NET Framework)
- Visual Studio

## Como rodar

Cada pasta é uma solution independente. Abra o arquivo `.sln` correspondente
no Visual Studio e rode com `F5`.

## Nota

Este é um repositório de exercícios de estudo — o código reflete o nível da
disciplina na época e não segue necessariamente as melhores práticas atuais.
